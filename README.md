# نورث للمسار المالي

نموذج الواجهة الأمامية للصفحة الرئيسية لمنصة نورث للمسار المالي، منصة تعليمية سعودية للأسواق المالية.

## المحتويات

- `index.html` — الصفحة كاملة، HTML و CSS و JavaScript في ملف واحد بدون أي اعتماديات بناء.
- `assets/` — ملفات الشعار ونسخه البيضاء، وملمس الحبيبات.

## التشغيل محلياً

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## ملاحظات

- الصفحة تدعم RTL بالكامل، ولها وضعان فاتح وداكن يتبعان إعداد النظام مع زر تبديل يدوي.
- الخطوط من Google Fonts: Readex Pro و IBM Plex Sans Arabic و IBM Plex Mono.
- الأرقام والأسعار المعروضة تجريبية لغرض اعتماد التصميم.
